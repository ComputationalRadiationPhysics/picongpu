How to Participate as a Developer
================================================================================

## How to Contribute

We welcome contributions! Follow this short checklist to get started:

1. **Fork** the [repository on GitHub](https://github.com/ComputationalRadiationPhysics/picongpu).
2. **Clone** your fork locally and create a new branch:

   ```sh
   git clone git@github.com:<your-username>/picongpu.git
   cd picongpu
   git checkout -b <feature-name>
   ```

3. **Make** your changes.
4. **Run** the code style checks and CI locally (see the
   [style guide](https://picongpu.readthedocs.io/en/latest/dev/styleguide.html)
   and [CI documentation](https://picongpu.readthedocs.io/en/latest/dev/ci.html)).
5. **Commit** following the
   [commit guidelines](https://picongpu.readthedocs.io/en/latest/dev/docs/COMMIT.html).
6. **Push** your branch and open a Pull Request.
7. **Review**: ensure the CI passes and address any review comments.
